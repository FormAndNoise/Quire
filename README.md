# Quire

**Quire** is a desktop utility for physical bookbinders that automates the page ordering, signature parcel mapping, and 2-up sheet imposition of multi-page PDF documents for Coptic and codex bindings.

---

## Features
- **Configurable Signature/Parcel Sizes**: Group sheets into custom parcel counts (e.g. 3 sheets = 12 booklet pages).
- **Blackout Sheets**: Specify blank endpapers and blackout sheets for cover paste-downs.
- **Duplex Modes**: Output single duplexed PDFs for two-sided printers or separate Front/Back files for manual duplex printing.
- **Automated Directory Watcher**: Watches an `Input/` folder and automatically processes new incoming PDFs.

---

## Getting Started
```bash
python app.py
```
Or double-click `start.bat`.
