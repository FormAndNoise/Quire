# AGENTS.md — Quire

Bookbinding print-imposition utility converting multi-page PDFs into duplexed, sequence-ordered 2-up signature parcels.

## Brand Identity & Standards
- **Product Name**: **Quire** (Repo: `quire`, CLI: `quire`)
- **Accent**: Bookcloth Crimson (`#8E2F45` / Dark: `#BC5570`)
- **Job Line**: *"Imposes multi-page PDFs into duplexed, sequence-ordered signatures for physical bookbinding."*
- **Symbol**: 24×24u, 1.75u stroke, folded signature parcel with exposed Coptic chain-stitch and 1 solid locking pip.
- **Suite Context**: Form & Noise Atelier Loose Endorsed Family. Space Grotesk (Wordmarks), Inter (UI), IBM Plex Mono (CLI).

## Usage
```bash
python app.py
```
